# Scheduled automations

Claude can run a task on a schedule without anyone starting it. I use this for routine checks that used to eat a few minutes every morning. Now they don't.

## Weekday morning brief

Every weekday morning Claude puts together one page: what's on today's calendar, which messages need an answer, and what's due. I read it on my phone before the day starts instead of opening four apps.

## Daily public-data capture

Every morning Claude opens a public website in the browser, takes screenshots of that day's figures, saves them to a dated file and sends them to me with the three numbers I care about pulled out.

Rules written into the task:

- Work in its own browser tab and never touch my open tabs.
- Never accept cookie banners or agreements on my behalf.
- Never overwrite an earlier day's file.
- If the browser or the site is unavailable, say so once and stop. No endless retries.

## Why this matters

Each task is a short written instruction, not code. Once tested, it runs the same way every day.

When something breaks, I get a clear message. Not a silent gap.
